Contexte

À partir du jeu de données Contoso (ventes d'un distributeur multicanal), suivre le chiffre d'affaires et la marge, et repérer les magasins, produits et promotions qui tirent la performance vers le haut ou vers le bas.

Pipeline ETL · Excel vers Data Warehouse

Talend Snowflake SQL Power BI Projet de Master
Contexte

Des dépenses suivies dans un fichier Excel sur Google Drive, difficile à exploiter dans le temps. Objectif : automatiser l'alimentation d'un entrepôt de données et en tirer un tableau de bord de suivi.

Démarche
  • Architecture ODS / DWH et modélisation dimensionnelle (dimensions et table de faits)
  • Jobs Talend d'ingestion, de transformation et d'alimentation
  • Jobs Master pour orchestrer les traitements, contextes pour les paramètres d'exécution et de connexion
  • Récupération automatique depuis Google Drive et chargement dans Snowflake
  • Alimentation des dimensions et de la table de faits en SQL, restitution dans Power BI

CartoDataSup · Analyse des données Parcoursup

Power BI PostgreSQL Django React.js Chart.js Pour Kaléinno
Contexte

Rendre lisibles les données open data Parcoursup pour des décideurs : où se trouvent les formations, lesquelles sont sélectives, et comment l'accès varie selon le secteur et le territoire.

Démarche
  • Structuration des données Parcoursup dans PostgreSQL
  • Indicateurs : taux d'admission, taux de remplissage, ratio capacité / candidats, admis par type de bac, public / privé, répartition géographique
  • Prototypage des visualisations dans Power BI
  • Application web avec filtres (région, académie, département, secteur, sélectivité) et import de fichiers CSV
